
# IoT Smart Parking System

## Overview

An IoT-based Smart Parking system implemented in Cisco Packet Tracer using a programmable MCU and Python scripting.

The system monitors sensor inputs and controls parking-related devices automatically.

## Components

- Motion Sensor
- Smoke Sensor
- Garage Door
- Siren
- LCD Display
- Smart LED

## Implementation

The MCU runs a Python script to:

- Monitor motion sensor input.
- Read smoke sensor values.
- Detect potential smoke or fire conditions.
- Control the garage door.
- Activate the siren when smoke is detected.
- Display system status on the LCD.
- Control the Smart LED according to sensor conditions.
